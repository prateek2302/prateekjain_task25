# Sole House

A responsive React shoe-store demo built with Vite. Browse the collection, filter shoes by category, and manage the shopping bag with React's `useState` hook.

## Features

- Shoe cards with name, category, color, price, and product image
- Category filters for running, lifestyle, and trail shoes
- Add shoes to the bag and increase quantities
- Decrease an item's quantity or remove it from the bag
- Live item count, subtotal, and free-shipping progress
- Responsive product catalog and shopping bag

## Run locally

1. Install Node.js (18 or newer).
2. From this folder, run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.
4. Run `npm run build` to create the production build in `dist/`.

Product photography and web fonts load from external Unsplash and Google Fonts URLs.
